# Hi, I’m Lewis Webster

Software developer based in Brighton, working with **JavaScript, TypeScript, React and Next.js**.

I have professional experience as a React Engineer at Bluecrest Wellness, building customer-facing features including health-data visualisations and payment flows. My work has involved API integration, accessibility improvements, automated testing and investigating production issues, alongside collaboration with designers, product managers and QA.

Before moving into software development, I worked in English language teaching and adult education. That experience shapes how I approach development: understanding users’ needs, explaining ideas clearly and making complex information easier to use.

I completed the Northcoders full-stack development bootcamp in 2024 and hold an MA in Applied Linguistics from the University of Sussex.

## Featured projects

### [The Ana-gram-miser](https://github.com/lw1066/anagrammer2)

An interactive anagram helper with letter-position constraints, wildcard support and dictionary definitions. An AI assistant connects natural-language requests to the application’s search tools.

**React · TypeScript · Vite · Tailwind CSS · SWR · Netlify Functions · Groq · Jest**

[Try the app](https://anagrammiser.netlify.app/)

### [Spoken BNC Concordancer](https://github.com/lw1066/spoken_bnc_concordancer)

A tool for exploring words, phrases and collocations in the Spoken British National Corpus 2014. It turns annotated XML into a searchable database and presents language examples through concordance tables and interactive distribution charts.

This project brings together my interests in applied linguistics, data and software development.

**React · TypeScript · Express · SQLite · Python · Recharts · Jest**

[Try the app](https://spokenbncconcordancer.netlify.app/)

### [Beach Buddy — public web version](https://github.com/lw1066/beach-buddy-web)

A swimming-information app combining bathing-water classifications, pollution risk forecasts, weather, tides and nearby amenities. Adapted from my React Native mobile project, with an interactive web map and authenticated AWS API requests.

The web version is deployed; Android release work is pending, with further iOS development planned.

**React · React Native Web · Expo · Leaflet · AWS Amplify · Cognito · Lambda · Netlify**

[Try the app](https://beachbuddyweb.netlify.app/)

### [Curation Creation](https://github.com/lw1066/curationcreation)

Search collections from the Victoria and Albert Museum and Europeana, explore objects and save a personal exhibition. The application integrates different catalogue APIs, handles their pagination models and stores users’ selections in Firestore.

**Next.js · React · TypeScript · Firebase Authentication · Cloud Firestore · REST APIs**

[Try the app](https://curationcreation.netlify.app/)
